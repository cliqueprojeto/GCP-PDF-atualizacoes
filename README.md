# GCP-PDF — Atualizações

Este repositório distribui **somente os instaladores** do GCP-PDF, o editor de PDF da
[Gestão Cultural Pro](https://gestaoculturalpro.com.br/), desenvolvido por Bruno Albertini.

- Baixe a versão mais recente em **[Releases](../../releases/latest)** (`GCP-PDF-Instalador-…-x64.exe`).
- Quem já usa o GCP-PDF recebe as novas versões pelo próprio programa, sem precisar configurar nada.
- Cada versão traz a lista de **Novidades** e o código de integridade (SHA-256) do instalador.

O código-fonte do GCP-PDF é proprietário e não é distribuído aqui.
